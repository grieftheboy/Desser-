# Aether De-Esser VST3 & AU Plugin

Built with C++ JUCE DSP.

### How to download your compiled VST3:
1. Go to the "Actions" tab at the top of this GitHub repository.
2. Click on the latest workflow run.
3. Scroll to the "Artifacts" section at the bottom to download your Windows VST3 or macOS VST3/AU!
